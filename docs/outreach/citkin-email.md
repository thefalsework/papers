1. **Uniqueness of the ordinary element.** In any Heyting algebra in which every element is a value of some x_n in g — so in every Z_n, and in F_HA(1) itself, by your Theorem 3 — if g is ordinary, then g is the *unique* ordinary element of the algebra.   * **[Correction note, 2026-07-08; verified against the original email.]** The step "second ordinary via `a ∨ b`" is impossible as written: for dense `b`, `¬(a ∨ b) = ¬a ∧ ¬b = ⊥`, so `a ∨ b` is itself dense and can never be ordinary. The original email (2026-06-13) reads verbatim "if it were incomparable with a dense element b, then a ∨ b would be a new ordinary element" — so the transcription above is faithful and the slip is in the source, almost certainly a pen-slip for **`a ∧ b`**, which carries the argument: `¬(a ∧ b) = ¬a ≠ ⊥`, `¬¬(a ∧ b) = ¬¬a ≠ a ∧ b`, and `a ∧ b ≠ ⊥` (else `a ≤ ¬b = ⊥`); so `a ∧ b` is ordinary, hence `= a`, giving `a ≤ b`. No conflict with the converse refutation: Prop 3.1 gives subalgebra containment, not generation.
3. **Corollary 3.9:** a finitely generated nodeless Heyting algebra is Boolean iff it contains no ordinary elements — overlaps the Glivenko-collapse facts (`boolean_no_ordinary` is the easy direction, in more generality); citable.
