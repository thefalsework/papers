# Registered spec: the capacity threshold (the work theorem)

Date: 2026-09-13. Registered after the Phase 0 literature check and
before any code or Lean. Companion to `second-law-spec.md` (same day).

## The question

The second-law package gave the thermodynamic reading one law. The
missing centerpiece was a *work theorem*: a statement of what
ordinariness buys a system, as a bound, independent of substrate. The
candidate: define the **capacity** of an element `k` as the size of
the subalgebra `⟨k⟩` it generates under the system's own operations
(meet, join, implication, bounds) — the structure one distinction can
manufacture from itself. Conjectured classification:

- `k` dense (`¬k = ⊥`): capacity ≤ 3 (`{⊥, k, ⊤}` closes).
- `k` regular (`¬¬k = k`): capacity ≤ 5 (`{⊥, k, ¬k, k ∨ ¬k, ⊤}`
  closes).
- `k` ordinary: capacity ≥ 6 (six explicit pairwise-distinct
  elements: `⊥, k, ¬k, ¬¬k, k ∨ ¬k, ⊤`).

Hence the threshold: **`k` is ordinary iff its capacity is at least
6.** Ordinariness is exactly the positional condition under which one
distinction generates strictly more structure than any classical or
degenerate element can.

## Phase 0 verdict, recorded first: the mathematics is Citkin's

The literature check (run before this spec was written) found the
classification **already in the literature**, in the program's own
best-known reference: Citkin, "An Algebraic Proof of the Nishimura
Theorem" (Logics, 2024):

- **Proposition 3**: a nontrivial algebra generated by a dense
  element is `Z_2` or `Z_3` — proved by exactly the `{0, g, 1}`
  closure observation. The dense bucket is his.
- **Propositions 2 + Theorem 6**: one-generated algebras of
  cardinality ≤ 5 are generated by regular or dense elements and are
  `Z_n`, `n ∈ [1, 5]`. The regular cap is his.
- **Proposition 4(c)**: an algebra generated by an ordinary element
  has more than five elements. The ordinary floor is his — and the
  repo has cited it as [C] since `NishimuraKernelLaw.lean` ("cited,
  not proved").
- Since `⟨k⟩` is a one-generated algebra and ordinariness transfers
  between an algebra and any subalgebra containing the element
  (negation and bounds are preserved), the general capacity threshold
  follows from his results plus the Nishimura classification.

**The novelty claim for the mathematics is dead on arrival, and this
spec records the kill before making any.** What is registered below
is a *formalization* claim and a *reading*, not a mathematics claim.

## What is registered

- **W1 (dense closure).** For dense `k`, the set `{⊥, k, ⊤}` is
  closed under `⊓`, `⊔`, `⇨` and contains the bounds. Kernel-checked
  abstractly (any Heyting algebra).
- **W2 (regular closure).** For regular `k`, the set
  `{⊥, k, kᶜ, k ⊔ kᶜ, ⊤}` is closed likewise. Kernel-checked
  abstractly. (Non-trivial entries: `kᶜ ⇨ k = k` uses regularity;
  `(k ⊔ kᶜ)ᶜ = ⊥`.)
- **W3 (ordinary floor).** For ordinary `k`, the six elements
  `⊥, k, kᶜ, kᶜᶜ, k ⊔ kᶜ, ⊤` are pairwise distinct. Kernel-checked
  abstractly. (This is a *direct* six-element argument, simpler than
  Citkin's quotient-by-dense-filter proof of 4(c); the distinctness
  of `k ∨ ¬k` from `⊤` uses distributivity.)
- **W4 (the threshold, iff).** `k` is ordinary **iff** every
  operation-closed set containing `k` contains six pairwise-distinct
  elements. Forward from W3 + closure; backward from W1/W2 (the
  explicit small closed set pigeonholes any six-element subset).
- **Oracle first**: before Lean, an exhaustive computational check on
  the down-set algebras of all posets on ≤ 4 elements (and a
  5-element sweep if cheap): classify every element, compute its
  closure capacity, verify the three buckets. **Kill W-K1**: any
  non-ordinary element with capacity ≥ 6, or any ordinary element
  with capacity ≤ 5, or any dense element with capacity > 3 — the
  hand proofs are wrong and the spec records it.

   contribution, if the Lean lands: first kernel-checked proof of the
   capacity classification, in fully abstract form (Citkin's Props
   2/3/4(c) + the threshold packaging as a single iff), closing the
   repo's oldest cited-not-proved item on this thread.
2. **What this means for the thermodynamic frame, stated plainly:**
   the frame's work law turns out to *exist in the literature* rather
   than to be generated by the frame. The frame gains consistency
   (its central predicted quantity — what ordinariness buys — is a
   theorem, with the threshold at six) and loses the generativity
   claim for this step (it located known mathematics; it did not
   produce new mathematics). Both facts go in the ledger. The
   second-law package remains the frame's one generated theorem.
3. **The capacity/work reading** (capacity as generative work, the
   threshold as the price of the four-fold) is interpretation,
   grade-[O] prose, not part of the registered mathematics.

## Postscript (2026-09-13, same day): oracle passed, all four clauses kernel-checked

**Oracle** (`work-theorem/01-capacity-oracle.py`): all 87 posets on
≤ 5 elements (up to isomorphism), 938 elements classified and closed.
Dense capacity min 2 / max 3; regular min 2 / max 5; ordinary min 6 /
max 10. **No kill fired** — W-K1 clean.

**Lean** (`lean/FalseWorkPapers/Lattice/CapacityThreshold.lean`),
builds clean:

- **W1** `IsSubalgebraSet.dense_closed` — `{⊥, k, ⊤}` closed for
  dense `k`.
- **W2** `IsSubalgebraSet.regular_closed` — `{⊥, k, kᶜ, k ⊔ kᶜ, ⊤}`
  closed for regular `k` (regularity used exactly twice:
  `kᶜ ⇨ ⊥ = k`, `kᶜ ⇨ k = k`).
- **W3** `IsOrdinary.six_distinct` — the six witnesses pairwise
  distinct, by a direct argument (no quotient through the dense
  filter; distinctness of `k ⊔ kᶜ` from `⊤` is the one place
  distributivity enters).
- **W4** `isOrdinary_iff_six_le_capacity` — ordinary iff every
  operation-closed set containing `k` holds ≥ 6 elements.
